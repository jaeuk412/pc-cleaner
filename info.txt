내용은 LLM 기반 코딩 에이전트(Claude Code/codex 등)를 활용하여

전기·전자 엔지니어링 현업 문제 또는 일상·업무 자동화 도구를 직접 구현하고,

그 결과물을 GitHub를 통해 공유하는 실습 프로젝트입니다.

 

1) 제출 기한: 2026년 12월 13일(일요일) 23:59까지

2) 제출 방법:

- 완성된 GitHub 저장소를 반드시 Public(전체 공개) 상태로 설정한 뒤, LMS 과제 제출란에 저장소 URL 링크를 text 파일 형태로 제출.

- public설정이 꺼려질 경우 https://github.com/king-wss와 공유/ 비공개 설정후 공유가 안되서 그로인해 열람이 불가능할 경우 미제출로 처리될 수 있음.

- github에 발표자료와 소스코드,저장소 설명서를 올려놓고 공유

- 전체 소스 코드 및 샘플 데이터: 구현된 프로젝트 코드와 함께 타인이 즉시 테스트해 볼 수 있는 샘플 입력 파일(더미 데이터, 로그 샘플 등) 및 패키지 의존성 목록(requirements.txt 등)을 포함

- 발표 자료 (PPTX 또는 PDF): 프로젝트 기획 의도, 시스템 구조, LLM 활용 및 디버깅 과정, 실행 결과 화면(캡처 또는 시연 영상 링크)을 담은 5~10장 내외의 발표 자료를 저장소 내에 업로드

- 저장소 설명서 (README.md): 프로젝트 개요, 주요 기능, 실행 환경 설정 및 구동 명령어, 그리고 개발 과정에서 사용한 핵심 프롬프트와 문제 해결 과정을 요약하여 루트 경로의 README.md에 작성

3) 프로젝트 주제

* 아래 예시 중 하나를 선택하거나, 본인의 현업 및 일상에 필요한 자유 주제를 1가지 선정하여 진행

- HW 계측기 제어(PyVISA/SCPI) 및 하드웨어 테스트 자동화: 오실로스코프, 네트워크·스펙트럼 분석기, 파워서플라이를 제어하는 Python 스크립트를 작성해 온도·전압별 반복 측정과 CSV 리포트 생성을 자동화

- 시뮬레이션(SPICE·EM) 배치 구동 및 파라미터 스윕: 텍스트 기반의 시뮬레이션 설정 파일(.net, .setup 등)을 파라미터 조건별로 대량 생성하고, 터미널 CLI로 시뮬레이터를 연속 실행한 뒤 수렴 결과만 추출

- 대용량 센서 덤프 및 장비 에러 로그 분석: 기가바이트 단위의 원시 ADC 데이터나 통신 에러 로그를 파싱해 이상치(Glitch) 발생 구간을 찾고, NumPy·SciPy를 활용해 FFT 주파수 스펙트럼 및 파형 그래프를 자동 출력

- CI/CD 파이프라인 스크립트 세팅: 프로젝트의 빌드 및 배포 환경을 파악한 뒤 GitHub Actions, GitLab CI용 YAML 워크플로우 파일을 생성하고 린트(Lint) 및 테스트 자동화 파이프라인을 구축

- 지능형 메일 분류 및 요약: Gmail이나 Outlook API를 연동해 미확인 메일의 중요도를 판별하여 라벨링하고, 핵심 용건과 회신 초안을 매일 아침 요약 리포트로 생성

- 주간·월간 업무 보고서 생성: 한 주 동안 작성된 일일 업무 메모나 진행 내역 파일들을 취합해 성과 중심의 마크다운(Markdown) 또는 워드(DOCX) 보고서 초안을 작성

- 웹 트렌드 및 뉴스 스크래핑: 지정된 뉴스 사이트나 업계 게시판의 최신 글을 주기적으로 수집하는 크롤러를 짜고, 키워드별 동향을 분석해 슬랙(Slack)이나 이메일로 알림을 보냄

- PC 용량 확보 및 백업 자동화: 하드디스크 공간을 차지하는 중복 대용량 파일과 오래된 임시 파일을 찾아 정리하고, 중요 작업 폴더를 날짜별로 압축해 클라우드로 자동 백업
